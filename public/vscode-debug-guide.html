🔧 VS Code Next.js Debug Guide

Complete debugging setup for localhost:3000

🔧 Server-Side Debugging (API Routes, Server Components)

Quick Start:

  1. Open VS Code
  2. Press Cmd+Shift+D (Debug panel)
  3. Select "Debug Next.js (Server Only)"
  4. Click ▶️ green play button

What You Can Debug:

  • 📡 API routes (/api/*)
  • 🔐 Authentication flow
  • 💾 Database operations
  • 📱 WhatsApp OTP service

Set Breakpoints In:

src/app/api/auth/forgot-password-otp/route.ts src/app/services/UnifiedWhatsAppService.ts src/app/services/OTPService.ts src/app/models/User.ts

🌐 Client-Side Debugging (React Components)

Quick Start:

  1. Open VS Code
  2. Press Cmd+Shift+D (Debug panel)
  3. Select "Debug Next.js (Client Only)"
  4. Click ▶️ green play button
  5. Chrome will open with DevTools attached

What You Can Debug:

  • ⚛️ React components
  • 🎯 Event handlers
  • 📊 State management
  • 🌐 Frontend API calls

Set Breakpoints In:

src/app/auth/forgot-password/page.tsx src/app/components/BookingForm.tsx src/app/components/Navigation.tsx

🚀 Full-Stack Debugging (Both Server + Client)

Method 1 - One Click:

  1. Select "Debug Next.js (Server + Client)"
  2. Click ▶️ - Debugs everything automatically

Method 2 - Advanced:

  1. Select "Debug Full Stack (Server + Browser)"
  2. Click ▶️ - Launches both debuggers
  3. Two debug sessions running simultaneously

⚡ Quick Debug Commands

Terminal Commands:

# Start with debugging npm run debug # Start with breakpoint on first line npm run debug:brk # Regular development (no debugging) npm run dev

VS Code Shortcuts:

  • F5 - Start debugging
  • F9 - Toggle breakpoint
  • F10 - Step over
  • F11 - Step into
  • Shift+F11 - Step out
  • Shift+F5 - Stop debugging
